# Clipboard history

K-Desktop keeps what you copy (texts, pictures and files) so you can paste it again, and it can be used instead of
Windows' own history.

## Opening it

- With its hotkey, in *Settings → Clipboard*. If you set it to **Win + V**, this history opens instead of Windows'
  one.
- From the tray: **Clipboard history**.
- From a command or a QuickMenu: the **Clipboard** action with **Show the history**.

It opens next to the mouse. Type to search and choose with ↑ ↓:

| Key | What it does |
|---|---|
| Enter (or click) | Pastes it in the window where you were |
| Shift + Enter | Pastes it without format |
| Ctrl + 1…9 | Pastes that row |
| Ctrl + P (or the row's pin) | Pins it (or unpins it) |
| Del | Deletes it from the history |
| Tab | Changes the filter: All, Text, Pictures, Files, Pinned |
| Esc | Closes it |

With a right click: paste, paste without format, **paste with a change** (upper case, lower case, each word capitalised,
remove extra spaces, clean links), copy without pasting, open the picture or the files' folder, pin and delete.

## Options

In *Settings → Clipboard*:

- **Keep what you copy**: off, nothing new is kept. From the tray, **Pause the history** stops it for a while.
- **Pictures**: copied pictures too (up to 20 MB each).
- **Assistants can read it**: to ask them «what did I copy before?»; they only see the texts.
- **How many to keep** (200 by default) and **Delete after days** (0: never). Pinned ones always stay.
- **Don't keep what is copied in**: programs whose copies are never kept; password managers by default.
- **Clear the history**: deletes everything but the pinned ones.

## Privacy

- It is kept encrypted for your Windows user and only on this PC (it is not in the backups).
- It never keeps what a program marks as private (password managers do) nor what K-Desktop pastes in passing, like the
  long texts of [Texts](texts.md).
- While K-Desktop is paused it keeps nothing either.
