# K-Desktop

<p class="lead">Keyboard and mouse shortcuts, QuickMenus, macros, events, voice control and a phone remote for Windows,
with optional desktop assistants powered by local AI.</p>

> [!WARNING]
> K-Desktop 5 is still under active development. Things change from one version to the next, and the assistant module
> and its SDK are being finished.
