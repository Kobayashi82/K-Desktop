A canvas on the overlay. Call Present(PixelRect, Action<DrawingContext>) only when something changed: the last frame stays on screen (also after the GPU is lost or comes back from a full-screen game), so an assistant at rest presents nothing and costs nothing.

Present(PixelRect, Action<DrawingContext>)

Draws a frame with WPF's drawing API: draw records into a DrawingContext whose coordinates are screen pixels; anything outside area is clipped. The host replays it with Direct2D, antialiased by the GPU. Frozen brushes, pens and geometries are cached between frames.
