Class Rope

Namespace
KDesktop.Assistant.Sdk
Assembly
KDesktop.Assistant.Sdk.dll

A rope (cable, hook line, leash) simulated with Verlet integration, in screen pixels like everything else. The start is always held (by the assistant); the end hangs free or is held too (stuck in a window, on a projectile). It only resists stretching, so it sags and goes slack, and it never gets longer than MaxLength while its end is free. It steps itself at a fixed 120 Hz whatever the frame rate, so it behaves the same on any screen.

Examples

var rope = new Rope(nose, hook, length: 300) { MaxLength = 420 };
// every tick:
rope.Start = nose; rope.PinEnd(hook);   // or rope.ReleaseEnd() to let it fall
rope.Step(tick.Elapsed);
rope.Draw(dc, pen);                      // inside a surface's Present
if (rope.IsTaut) PullWindow(rope.Pull); // what towing does with it
