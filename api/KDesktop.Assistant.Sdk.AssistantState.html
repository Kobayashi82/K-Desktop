States the module tells the assistant about; each assistant shows them its own way.

public enum AssistantState

Fields

Idle = 0
Listening = 1

Its wake word was heard, or its talk key or a long click: it is listening (also while dictating).

Thinking = 2

The AI is working on an answer.

ThinkingHard = 3

The AI thinks it over, slowly (it asked to, or the user said «think it over»): it may take half a minute.

LoadingBrain = 4

Its model is being loaded into memory before it can think (from a few seconds to a minute).

NoBrain = 5

The order needed the AI and there is none (no model, or its server does not answer). It comes right before Speaking, which says so: a shrug while it says it.

Speaking = 6
AwaitingConfirmation = 7

A yes/no question is waiting for the user (the little window that asks for permission).

Busy = 8

Carrying out an order: one of its tools or a command is running (Activity says which).

Sleeping = 9
