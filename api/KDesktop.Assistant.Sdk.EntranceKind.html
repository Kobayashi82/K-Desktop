Why an assistant comes onto the desktop (Enter(EntranceKind)).

public enum EntranceKind

Fields

Startup = 0

K-Desktop started, or the user switched the assistant module on: its full entrance.

Summoned = 1

The user put it on the desktop (Options, the tray, the panel): an entrance that says «here I am».

Reloaded = 2

It was already there a moment ago and comes back at once: a new version, another language, its data started afresh, its process restarted or recovering from a fall, a rebuild with --assistant-dev. Reappear where it was, with no show (what it saved on Reloading, in its data folder).
