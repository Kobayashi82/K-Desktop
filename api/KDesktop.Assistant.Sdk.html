Gesture

What the module wants to achieve; the assistant decides how. An assistant that only knows Gesture.Communicate and Gesture.React already works: for the rest the module falls back to Communicate and performs the action itself.

Gesture.ActivateWindow

Bring a window to the front (perch on it, knock on the door…). Commit when it should happen.

Gesture.Announce

it is about to say something on its own (a timer that rang, «avísame cuando» that happened, «Asistente: decir»), so it catches the user's eye first: it comes closer to the cursor, waves, blinks… The host waits for it (at most TimeLeft, about 2 s; half a second in «Fast») and then speaks with Gesture.Communicate: end as soon as it is done. Nothing to Commit.

Gesture.Communicate

The generic one: stay visible while the host shows Text in the bubble.

Gesture.GoTo

Go somewhere (fly, walk, teleport).

Gesture.Mark

Leave a mark somewhere for a while (beacon, flag, alarm clock), with an optional label.

Gesture.MoveWindow

Move a window to Destination. Either move it frame by frame with TryMove(long, PixelRect) and return PerformedSelf (K-Desktop then puts it exactly in place), or call Commit and let the module move it. If Window is maximized it arrives already restored by a previous PressButton(Restore).

Gesture.PointAt

Point at a window, a point or an area (a spotlight, an arm…).

Gesture.PressButton

Press a caption button. Call Commit() at the moment of the effect (when the shot hits): the window minimizes right then.

Gesture.React

A short reaction to how something went. Context says where it comes from, how many in a row and whether it is the first of the day, so the same reaction need not look the same every time.

Gesture.Scan

Sweep an area (screenshot, reading the screen).

Gesture.Typing

Pretend to type into a window (keys or text are being sent to it).

Gesture.WaitForWindow

Something was just opened: wait for its window. Appeared completes with the new window (or null when it does not show up in time).

Rope

A rope (cable, hook line, leash) simulated with Verlet integration, in screen pixels like everything else. The start is always held (by the assistant); the end hangs free or is held too (stuck in a window, on a projectile). It only resists stretching, so it sags and goes slack, and it never gets longer than MaxLength while its end is free. It steps itself at a fixed 120 Hz whatever the frame rate, so it behaves the same on any screen.

ShowcaseItem

One of its own animations, for the showcase: a dance, a trick, the way it plays with a ball… What the host already asks of every assistant (entrances, exits, states, reactions, gestures) is not listed: the host launches those itself. K-Desktop shows these in the assistant's «Try» tab and in the catalog, and asks for one with PlayShowcaseAsync(string, CancellationToken).

SystemEvent

Things that happen on the PC, delivered to OnSystemEvent(SystemEvent) on the engine thread. They are what lets an assistant react on its own (the Lander jumps when a notification appears, goes to sleep when the user leaves…). Current is already up to date when one arrives.

SystemEvent.FastScroll

The user scrolled hard (several quick notches of the wheel), anywhere. Strength 0…1, positive downwards; Position is the cursor's.

SystemEvent.FullscreenChanged
SystemEvent.HourStruck

The clock struck an hour (local time).

SystemEvent.MonitorsChanged
SystemEvent.NotificationShown

A Windows notification (toast) appeared at Bounds.

SystemEvent.PauseChanged

K-Desktop was paused or resumed.

SystemEvent.PowerChanged
SystemEvent.QuietModeChanged
SystemEvent.RecycleBinEmptied
SystemEvent.ThemeChanged
SystemEvent.UserIdle

No input for Seconds (raised at 60 s and then every few minutes).

SystemEvent.UserReturned

One turn of the mouse wheel, only while the assistant asks for them (WatchWheel).

SystemEvent.WindowActivated
SystemEvent.WindowClosed

SystemState

TaskbarInfo

The taskbar of one monitor and, on the main one, the notification area and the clock.

Variety<T>

A set of variants to choose from at random: several entrances, reactions, idle animations or lines, so the assistant does not do the same thing every time. Each variant has a weight (how often it comes up compared with the others) and a cooldown (seconds it rests after being picked). It never picks the same one twice in a row while there is another to choose. Give it a seed in tests to always get the same sequence.

WindowInfo

A visible top-level window as the window manager sees it.

Interfaces

IAssistant

An assistant: a character that lives on the desktop. The host (K-Desktop's assistant process) loads it from its package, gives it the world and its services, and asks it for gestures; the assistant never sees the AI, the tools, the pipe or K-Desktop.

IAssistantHost

Everything the host offers an assistant. Use it from the engine thread unless a member says otherwise.

IAssistantLog

Its lines go to K-Desktop's assistant log, prefixed with its id.

IAudio

Sound. The host mixes everything and applies the user's volume for assistants.

IGestureContext

What the module gives an assistant while it performs a gesture.

IHitArea
IKeyboard

The keyboard, for assistants with a manual mode (the Lander's game). Reading the state is always allowed; capturing keys makes K-Desktop swallow them so the application in front does not get them as well.

ILoop
IPointer

The mouse. The overlay lets every click through; to be clickable an assistant places hit areas over its body (invisible windows with that shape). Their events arrive at OnPointer(PointerEvent). The right button is the host's: it opens the assistant menu (talk, write, extras, settings…).

IRendering

Drawing services. The host keeps one transparent overlay over every monitor that never takes the mouse or the focus; each surface is a small canvas on it that the compositor moves for free.

ISound
ISurface

A canvas on the overlay. Call Present(PixelRect, Action<DrawingContext>) only when something changed: the last frame stays on screen (also after the GPU is lost or comes back from a full-screen game), so an assistant at rest presents nothing and costs nothing.

IWindowServices

Moving and changing windows from the assistant process.

IWorld

The desktop as the host sees it.
