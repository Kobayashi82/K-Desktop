Class Variety<T>

Namespace
KDesktop.Assistant.Sdk

A set of variants to choose from at random: several entrances, reactions, idle animations or lines, so the assistant does not do the same thing every time. Each variant has a weight (how often it comes up compared with the others) and a cooldown (seconds it rests after being picked). It never picks the same one twice in a row while there is another to choose. Give it a seed in tests to always get the same sequence.

Examples

private readonly Variety<Clip> _happy = new Variety<Clip>()
    .Add(Clip.Jump)
    .Add(Clip.Spin, weight: 0.5)
    .Add(Clip.Backflip, weight: 0.2, cooldown: 120);   // rare, and never twice in two minutes
// in React(Happy):
Play(_happy.Pick());
// only the ones that fit where it stands:
Play(_happy.Pick(clip => clip.FitsOnTaskbar || !onTaskbar));

Remarks

Safe to use from several threads (the engine thread and a gesture).
