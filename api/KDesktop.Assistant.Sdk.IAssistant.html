An assistant: a character that lives on the desktop. The host (K-Desktop's assistant process) loads it from its package, gives it the world and its services, and asks it for gestures; the assistant never sees the AI, the tools, the pipe or K-Desktop.

public interface IAssistant : IDisposable

Remarks

One thread. Every member is called on the host's engine thread, and so are the continuations of awaits inside them (the thread has its own synchronization context). No locking is needed; never block it.

The host only wakes it when needed. Tick(TickInfo) returns how long it can sleep: an assistant at rest asks for a few ticks per second (or fewer) and draws nothing, which keeps the cost close to zero; while moving it asks for one tick per frame and the host paces it with the compositor.

Failures are contained. An exception in any member is logged; several in a row unload the assistant.

Only the essentials are required. Attach(IAssistantHost), Enter(EntranceKind), ExitAsync(ExitKind, CancellationToken), Tick(TickInfo), PerformAsync(Gesture, IGestureContext, CancellationToken), SetState(AssistantState, StateDetail) and BubbleAnchor; every other member has a default that does nothing (or says no), to implement when the character has something to show.

ShowSpeech(SpeechText)

Shows what it says its own way, for an assistant whose manifest says "speech": "own": a balloon of its own, a sign it holds up, words in its cloud… The host calls it each time the answer grows while it is being written (Finished false), with all of it when it is ready, and again with a later Until while its voice is still saying it. Each call replaces the text of the one before. The host still keeps the timing, the voice and the chat: show it until HideSpeech(). Return false when it cannot now (hidden, in the middle of a manoeuvre, it does not fit): the host shows its own bubble instead, for the rest of that answer. Not called while the user chose K-Desktop's bubble for it.
