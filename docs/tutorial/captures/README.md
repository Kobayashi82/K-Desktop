# Capturas para el vídeo

Capturas reales de K-Desktop (tema oscuro) que usa `docs/tutorial/video`: en `en/` las del vídeo en inglés y en `es/`
las del vídeo en español (las que falten se toman de `en/`). Los nombres esperados están en `docs/tutorial/video/README.md`. Las que falten se sustituyen
por las interfaces recreadas del propio vídeo.
