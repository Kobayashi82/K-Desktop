# Home router quick guide

The router is a FRITZ!Box 7590 in the hallway cupboard. Its web page is http://192.168.1.1 and the admin password is in the password manager under "Router".

## Wi-Fi
- Main network: **Casa-5G** (5 GHz) and **Casa** (2.4 GHz).
- Guest network: **Casa-Guests**, password on the fridge. It turns itself off every night at 01:00.

## If the internet stops working
1. Look at the Power and DSL lights. DSL blinking means the line is down: call the provider on 900 123 456.
2. Restart the router from the web page (System > Backup > Restart) or unplug it for 30 seconds.
3. The NAS ("vault") and the printer keep their fixed addresses: 192.168.1.20 and 192.168.1.30.

## Port forwarding
Port 32400 goes to the NAS for Plex. Nothing else is open.
